Дополнение для Recount 3.3.5a. RecountHealAndGuessedAbsorbs - это дополнение создано для владельцев валанира и жрецов в специализации "Послушание", показывая их поглощение урона+исцеление. С новым Recount аддон отключается сам: поглощение входит в штатный режим Recount «Эффективное исцеление», а отдельно его показывает режим «Поглощение».
