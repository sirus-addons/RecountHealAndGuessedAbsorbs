Дополнение для Recount 3.3.5a. RecountHealAndGuessedAbsorbs - это дополнение создано для владельцев валанира и жрецов в специализации "Послушание", показывая их поглощение урона+исцеление. Режим «Исцеление и поглощение» складывает исцеление и поглощение урона щитами, которое Recount берёт из боевого журнала по данным сервера.
